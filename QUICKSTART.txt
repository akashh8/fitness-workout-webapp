## 🚀 How to Run the Application

### Step 1: Set Up MongoDB

Option A - Local MongoDB:
1. Make sure MongoDB is installed and running on your machine
2. MongoDB should be accessible at: mongodb://localhost:27017

Option B - MongoDB Atlas (Cloud):
1. Create a free account at https://www.mongodb.com/cloud/atlas
2. Create a cluster and get your connection string
3. Update the MONGO_URI in your .env file

### Step 2: Start the Backend

1. Open a terminal in: d:\CC lab\fitness-workout-webapp\backend
2. Create .env file:
   copy ..\.env.example .env
3. Install dependencies:
   npm install
4. Start the server:
   npm start
   (or 'npm run dev' for auto-reload with nodemon)

Backend will run at: http://localhost:5000

### Step 3: Start the Frontend

1. Open a NEW terminal in: d:\CC lab\fitness-workout-webapp\frontend
2. Install dependencies:
   npm install
3. Start the development server:
   npm run dev

Frontend will run at: http://localhost:5173

### Step 4: Open in Browser

Navigate to: http://localhost:5173

## 🔧 API Endpoints

GET    /api/workouts          - Get all workouts
GET    /api/workouts/:id      - Get single workout
POST   /api/workouts          - Create new workout
PUT    /api/workouts/:id      - Update workout
DELETE /api/workouts/:id      - Delete workout
POST   /api/bmi/calculate     - Calculate BMI

## 📝 Environment Variables (.env)

PORT=5000
MONGO_URI=mongodb://localhost:27017/fitness-workout

For MongoDB Atlas:
MONGO_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/fitness-workout
